# [Настройка](#оглавление)
Раздел будет дополнен.

Самым важным параметром после названий топиков является положение IMU в системе координат LiDAR'a: `extrinsicTrans:  [ -0.154,  0.0, -0.251]`. При неверном значении работа алгоритма будет нарушена.

# [Сохранение карты](#оглавление)
Для сохранения карты необходимо ОБЯЗАТЕЛЬНО обновить окружение в терминале, чтобы сервис стал доступен, и вызвать его:
```
  ros2 service call [service] [resolution] [destination]
```
Пример:
```
cd ~/t21_ws/
. install/setup.bash
ros2 service call /lio_sam/save_map lio_sam/srv/SaveMap "{resolution: 0.2, destination: /Downloads/service_LOAM}"
```
При использовании `rqt_gui service_caller` также необходимо обновить окружение.
