# Power Monitor ROS2 Package

Мониторинг аккумулятора робота через USR-DR134 (RS485→TCP), публикация данных в ROS2
и вывод состояния в виде TUI-интерфейса в терминале.

---

## Описание

`power_monitor` — ROS2-пакет, обеспечивающий получение параметров Li-ion аккумулятора (6S)
через протокол Modbus RTU-over-TCP.

Используется оборудование:
- аккумулятор с интерфейсом RS485;
- преобразователь USR-DR134 (TCP Server → RS485);
- ROS2-компьютер, подключённый по Ethernet.

Пакет публикует данные в топик:

\`\`\`bash
/battery_state   # sensor_msgs/msg/BatteryState
\`\`\`

Также реализован TUI-интерфейс — визуальная «полоска» уровня заряда в терминале.

---

## Функциональность

### Чтение параметров аккумулятора по Modbus

Используются регистры:

| Параметр              | Регистр | Масштаб      |
|-----------------------|---------|--------------|
| Напряжение            | 0x000E  | мВ → В       |
| Ток                   | 0x000F  | мА → А (int) |
| SOC (RelStatCharge)   | 0x0012  | 0.1 %        |
| Остаточная ёмкость    | 0x0013  | мА·ч (может быть 0xFFFF) |

### Публикация в ROS2

Нода `battery_state_node` публикует сообщение `sensor_msgs/BatteryState`:

- \`voltage\` — напряжение, В;
- \`current\` — ток, А (со знаком, заряд/разряд);
- \`percentage\` — уровень заряда 0..1 (нормализованный SOC);
- \`present\` — флаг наличия батареи.

### TUI-интерфейс (battery_tui)

Нода `battery_tui` подписывается на `/battery_state` и рисует в терминале полоску:

\`\`\`
[##############--------------]  47.5%  U=22.30 V  I=-0.452 A
\`\`\`

Цвета:
- зелёный — > 50 %;
- жёлтый — 20–50 %;
- красный — < 20 %.

## Подключение оборудования

### 1. Аккумулятор → USR-DR134

RS485 линии:

| Аккумулятор | USR-DR134 |
|-------------|-----------|
| A           | RS485-A   |
| B           | RS485-B   |
| GND         | GND       |

### 2. USR-DR134 → сеть

Основные параметры:

- Режим: **TCP Server**;
- Порт: например, **5020**;
- Transparent mode: **ON** (прозрачная передача Modbus-кадров);
- IP-адрес, например: **192.168.3.50**;
- Маска: `255.255.255.0`;
- Gateway: IP роутера робота (например, `192.168.3.1`).

ROS2-компьютер должен иметь возможность достучаться до этого IP/порта.

## Установка пакета

Предполагается, что рабочий каталог ROS2 — \`~/ros2_ws\`.

### 1. Клонирование

\`\`\`bash
cd ~/ros2_ws/src
git clone git@github.com:dakolzin/USR-DR134-GUI.git
\`\`\`

### 2. Сборка

\`\`\bash
cd ~/ros2_ws
colcon build
source install/setup.bash
\`\`\`

---

## Запуск

### Вариант 1 — через launch-файл (оба узла сразу)

\`\`\`bash
ros2 launch power_monitor battery_monitor.launch.py
\`\`\`

Запускаются:
- `battery_state_node` — читает Modbus через USR-DR134 и публикует `/battery_state`;
- `battery_tui` — отображает уровень заряда и параметры батареи в терминале.

### Вариант 2 — по отдельности

Только модуль чтения батареи:

\`\`\`bash
ros2 run power_monitor battery_state_node
\`\`\`

Только TUI-интерфейс:

\`\`\`bash
ros2 run power_monitor battery_tui
\`\`\`

## Важные замечания по батарее (6S Li-ion)

Для 6S Li-ion (номинал ≈ 22.2 В):

| Напряжение (примерно) | SOC (примерно) | Комментарий                |
|------------------------|----------------|----------------------------|
| 25.2 В                | ~100 %         | Полный заряд               |
| 22.8 В                | ~60 %          | Нормальная работа          |
| 21.0 В                | ~20 %          | Желательно ехать на зарядку|
| 19.8 В                | ~0 %           | Глубокий разряд            |
| < 18.5 В              | —              | Опасно для ячеек           |

**Важно:**  
~18 В (3.0 В на элемент) — это уже фактически «убийственный» разряд для Li-ion.  
Для робота разумно:
- при 21.0–20.5 В выдавать предупреждение оператору;
- при ~20 В — жёстко блокировать выполнение миссий и требовать зарядку.
